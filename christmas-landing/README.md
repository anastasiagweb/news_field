# Лендинг «Weihnachten zum Lesen» — easyOriginal

Рекламный лендинг для Meta Ads: рождественские книги на итальянском, французском и испанском.
Язык страницы немецкий, как и в магазине easyoriginal.com.

Все данные взяты из магазина (WooCommerce API, 4 ноября 2026): названия, ID товаров и вариаций,
цены, тексты, фото, пробы текста и аудио.

## Что на странице

Оформление: светлый первый экран на бумажной фактуре, золотое тиснение на заголовках,
зелёный блок «два издания», рубиновый блок подарков со звёздами, гирлянда в финальном блоке.
Все украшения нарисованы кодом (SVG/CSS), внешние картинки — только фото товаров.

1. **Hero**: оффер и большое фото подарочного набора, которое плавно меняется Италия → Франция → Испания (можно переключить вручную).
3. **Книги**: выбор страны открытками-иллюстрациями, переключатель издания (Frank-Lesemethode A1–A2 / Mit Worterklärungen A2–B1).
   - Комплект из 3 книг с выбором формата: Taschenbuch + Audio-Online, + Audio-CD, PDF, ePub. Цена считается сразу.
   - Три отдельные книги: обложка, сюжет одной строкой, формат, кнопка покупки.
   - Полные описания (комплекта, каждой книги с героями, состава подарочного набора) **свёрнуты** под «Worum geht’s?», чтобы не мешать.
4. **Два издания**: раскрытая книга — реальная первая страница в обоих изданиях и настоящая аудиопроба.
5. **Подарочные наборы**: 3 книги + Schreibset Deluxe (Marmorträume для IT/FR, Eleganz der Natur для ES), с Audio-Online или CD.
6. Кому подарить, почему это работает, FAQ (доставка: бесплатно от 39 € по ЕС), финальный CTA и счётчик дней до Сочельника.

## Как работает покупка

Каждая кнопка ведёт прямо в корзину магазина, товар уже добавлен:

```
https://easyoriginal.com/warenkorb/?add-to-cart=<товар>&variation_id=<вариация>&attribute_pa_buch-ebook=<формат>
```

Проверено на трёх типах товаров: комплект, отдельная книга и подарочный набор (наборы раскладываются в корзине на компоненты).
UTM-метки и `fbclid` из рекламной ссылки передаются в корзину, поэтому атрибуция сохраняется.

## Пиксель Meta

- Используется пиксель магазина `1076640955760504` (`content.js` → `metaPixelId`).
- Пиксель загружается **только после согласия** в cookie-баннере (требование GDPR для DE/AT).
- События:
  - `PageView` и `ViewContent` при загрузке;
  - `AddToCart` с `value`, `currency: EUR` и ID вариации на каждой кнопке покупки;
  - кастомные `Sprachwahl`, `Ausgabewahl`, `Hoerprobe` и `CTA`.
- `Purchase` отправляет сам магазин, пиксель там уже стоит.

## Ссылки для рекламы

Язык можно открыть сразу из объявления. Тогда страница прокручивается к нужным книгам.

| Аудитория | Ссылка |
|---|---|
| Все языки | `.../index.html` |
| Итальянский | `.../index.html?lang=it` |
| Французский | `.../index.html?lang=fr` |
| Испанский | `.../index.html?lang=es` |
| Начинающие / знающие | добавить `&ausgabe=frank` или `&ausgabe=wort` |
| Сразу к подаркам | добавить `&ziel=geschenk` |

Например: `index.html?lang=fr&ausgabe=frank&ziel=geschenk&utm_source=meta&utm_campaign=weihnachten_fr`.

## Где разместить

Это статическая страница без сборки: `index.html`, `styles.css`, `app.js`, `content.js` и папка `img/` (около 4 МБ, WebP).
Подходит любой хостинг:

- папка на сервере магазина, например `easyoriginal.com/weihnachten/` (FTP или файловый менеджер хостинга);
- Netlify, Vercel или Cloudflare Pages: перетащить папку `christmas-landing`;
- GitHub Pages.

## Как менять содержимое

Всё лежит в `content.js`: цены, ID товаров, тексты, FAQ и пробы.
Английский позже добавляется так:

1. Добавить ещё один объект в `LANGS` по образцу итальянского (свои ID товаров, книги, проба, подарочный набор).
2. Положить в `img/` файлы `set-en-frank.webp`, `set-en-wort.webp`, `gift-en-frank.webp`, `gift-en-wort.webp` и обложки `cover-en-<key>-frank.webp` / `cover-en-<key>-wort.webp`.
3. В `index.html` при желании дописать «Englisch» в заголовок hero.

Вкладки, карточки и наборы появятся сами.
