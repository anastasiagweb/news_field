# Библиотека Classics — списки к изданию

По одному Word-файлу на язык:

| Файл | Изданий | Наборов | Скоро свободны |
|---|---|---|---|
| `Classics_EN_Английский.docx` | 205 | 31 | 20 авторов |
| `Classics_FR_Французский.docx` | 203 | 35 | 11 |
| `Classics_DE_Немецкий.docx` | 200 | 32 | 11 |
| `Classics_RU_Русский.docx` | 199 | 33 | 13 |
| `Classics_ES_Испанский.docx` | 191 | 32 | 9 |
| `Classics_IT_Итальянский.docx` | 178 | 31 | 9 |

Что внутри каждого файла:

- логика списка и правовая справка (Австрия/ЕС, отдельно США и исключения внутри ЕС);
- сводная таблица в порядке выпуска (первая, вторая и третья очередь);
- отдельные разделы «Тёплое», «С юмором», «Тепло и юмор вместе», «Подзабытые жемчужины»;
- готовые наборы;
- «Скоро станут свободными»: авторы, которые выйдут из-под охраны в ЕС в 2027–2029 годах;
- карточка каждой книги: о чём, почему, состав сборника, что учесть, права.

## Как обновить

Данные лежат в `data/<код>.json`, требования к списку — в `tools/SPEC.md`. Вторая проверка шла по `tools/AUDIT.md`, третья (права для Австрии/ЕС) — по `tools/AUDIT2.md`. Правки и дополнения каждого языка сохранены в `data/<код>.patch.json` и `data/<код>.patch3.json` (поле `report` — отчёт), применяются скриптом `tools/apply_patch.js`. После правки JSON пересоберите файл:

```bash
node tools/build.js data/ru.json Classics_RU_Русский.docx
```
