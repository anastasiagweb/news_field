# Библиотека Classics — спецификация списка по одному языку

## Задача
**ОБНОВЛЕНИЕ ОТ ЗАКАЗЧИКА: чем больше, тем лучше — цель 110–140 изданий (минимум 100), ничего лучшего не пропустить. Очереди: 1 ≈ 25–30, 2 ≈ 40–50, 3 — остальное. Наборов 16–22.**

Составить для одного языка список из **60–70 изданий** (минимум 60) классики в оригинале для изучающих язык (взрослые, уровни примерно A2+…C1, чаще B1–B2) и для тех, кто «классику не особо любит».
Издание = роман, повесть, пьеса, отдельный рассказ, ИЛИ **сборник коротких рассказов** (свой составительский сборник: 6–15 рассказов одного автора или на одну тему). Сборники очень приветствуются — для каждого перечисли состав.

## Критерии (в порядке веса)
1. Увлекательно: сюжет, интрига, юмор, тепло, атмосфера. Не «шедевр, который надо уважать», а то, что хочется дочитать.
2. Комфортно для изучающих: ясный язык, умеренная длина, диалоги, мало архаики/диалекта. Тяжёлые шедевры — только если очень популярны и с честной пометкой.
3. Коммерчески: узнаваемые названия (экранизации, школьная программа, бренды героев) + **подзабытые жемчужины** public domain, которые легко продать через тему/жанр.
4. Широта жанров: юмор, тёплое/уютное, детектив, приключения, фантастика, мистика/готика, любовь, сказки для взрослых, животные, путешествия, сатира.
5. Отдельно отметить **тёплое** (уютное, доброе, утешительное) и **с юмором**.

## Авторское право (на 2026 год) — строго
- Базово: автор умер **не позже 1955** (жизнь+70). Thomas Mann, Heinrich Spoerl (ум. 1955) — уже можно.
- **США**: свободно всё, опубликованное **до 1931**; позднее опубликованное может охраняться в США 95 лет — пометь в `rights`.
- **Россия**: жизнь+70; +4 года, если автор работал/воевал во время ВОВ; репрессированным и посмертно реабилитированным срок считается с года реабилитации (Хармс — нельзя). Зощенко, Паустовский, Пришвин — нельзя.
- **Испания**: авторы, умершие до 7.12.1987, — жизнь+**80** (значит, для Испании умер ≤1945). Мексика — жизнь+100, Колумбия — +80: помечай.
- **Франция**: военные продления (prorogations de guerre), «mort pour la France» +30 лет (Сент-Экзюпери во Франции под охраной) — помечай.
- Не включай: Christie, Wodehouse, Milne (ум. 1956), Simenon, Pagnol, Hesse, Kästner, Zoshchenko, Baroja, Jardiel Poncela, Guareschi, Campanile и т.п.
- Издаём оригинальный текст по прижизненной/старой редакции (не современные защищённые редакции).
- Поле `rights`: «свободно везде» или конкретная оговорка.

## Структура
- `tier`: 1 = первая очередь (~20 изданий, лучшее соотношение «интерес × доступность × продаваемость»), 2 = вторая (~20–25), 3 = третья (~15–25; жемчужины и более трудное).
- Внутри очереди — по убыванию приоритета.
- `bundles`: **10–14 наборов** по 3–6 изданий (ссылаются на `id`), с названием-продающим, концепцией и для кого. Разные оси: тема («Смешно о любви»), настроение («Уютные вечера»), жанр («Детективы до Агаты Кристи»), уровень («Первые книги в оригинале B1»), автор, «Подзабытые жемчужины», сезон («Рождество»), стартовый набор. Книга может входить в несколько наборов.

  "rights_note": "2–4 предложения: особенности авторского права для этого языка.",

- `warm` / `humor` — честно, не ставь всем подряд. `gem` = подзабытая / малоизвестная в России жемчужина.
- Объём в словах — оценка, округляй. Уровень — для оригинального неадаптированного текста.
- Весь текст полей, кроме названий/имён в оригинале, — по-русски, живо и конкретно, без канцелярита и штампов («шедевр мировой литературы» — нельзя).
- Проверяй факты: годы жизни, даты публикации, сюжет. Не выдумывай произведения. Если сомневаешься в правах — не включай.
- Валидируй JSON перед сдачей: `node -e "JSON.parse(require('fs').readFileSync('<path>','utf8'))"`.
