# Name Registry Schema

One `name_registry.md` per series, created by the series skill (slate phase) and extended by every book run. Rules: `references/onomastics.md`.

```
# Name Registry — <series title>

## Convention
- Transliteration: <letters, endings, diacritics>
- Strategy for unknown names: <n/a | neighbours' records | bynames | rule-based invention — rule stated>
- Forbidden list: bible §<n>

## Registry
| Name | Sex | Book | Story | Role | Status | Attestation (source key, date range) or rule | Meaning (if known) |
|---|---|---|---|---|---|---|---|

## Reserve pool (attested, not yet used)
| Name | Sex | Window / region | Status type | Source key |
|---|---|---|---|---|

## Exceptions
| Name | Reason approved in the bible |
|---|---|
```
