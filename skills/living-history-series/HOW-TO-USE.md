# living-history-series — как пользоваться

## Как устроен

Каждая фаза открывается разделом **Roles & Qualifications**. Это сильная персона, а в аудите — команда специалистов с регалиями, убеждениями и тем, чего они не допускают. Модель сначала становится этой командой, а потом работает по методике фазы.

Авторские фазы (проектирование рассказов, питчи) опираются на британскую литературную родословную исторической прозы — `references/lineage_EN.md`.

Примеров в навыке нет нигде.

## Что дать на вход

- **Обязательно:** цивилизацию.
- **По желанию:**
  - охват или фокус;
  - число книг (иначе конвейер предложит 8–20);
  - язык (по умолчанию британский английский) и уровень (по умолчанию B1–B2);
  - старые материалы как сырьё;
  - реестр линии `line_registry.md`.

## Фазы и команды

| Фаза | Команда | Остановка |
|---|---|---|
| P0 | Отдел выпуска серии + Managing Editor | ✔ подтвердить заказ |
| P1 | Исследовательская группа: ведущий историк, археолог материальной культуры, историк религии и ментальностей, эпиграфист-ономаст, историк среды, библиограф-аудитор источников, «разведчик сюжетов», консультант по наследию | |
| P2 | Совет архитектуры серии: издательский директор, специалист по хронологии, редактор британского рынка, редактор рынка учащихся, аудитор старых материалов | ✔ утвердить список книг |
| P3 | Комната авторов библии | |
| P4 | Панель аудита из 8 ролей + отдел фактчека | |
| P5 | Отдел правки библии | |
| P6 | Комната историй: глава (автор-шоураннер), историк рядом, контролёр разнообразия, регистратор имён | |
| P7 | Панель из 9 ролей + отдел фактчека | ✔ просмотреть план, выбрать режим питчей |
| P8 | Комната историй, сессия правки | |
| P9 | Автор питча + исследователь эпохи + планировщик заметок | |
| P10 | Панель из 10 ролей + отдел фактчека | |
| P11 | Отдел правки питча | |
| P12 | Отдел выпуска и выдачи | ✔ приёмка |

Аудит и правка повторяются, пока не останется 0 Critical и 0 Major. Если одна и та же причина блокирует дважды подряд, конвейер останавливается и предлагает три варианта: принять с оговоркой, переосмыслить, заменить.

## Что получится

- `bible.md`, `slate.md`, `pitches/bookNN_*.md`;
- `name_registry.md`, `sources.md`, `changelog.md`, `delivery_note.md`;
- вся история версий и отчётов.

Библия и один питч — это полный вход для `living-history-book`.
