# living-history-series — как пользоваться

## Как устроен

Каждая фаза открывается разделом ролей: это команда людей с регалиями, убеждениями и тем, чего они не допускают. Модель сначала становится этой командой, а потом работает по методике фазы.

- **У каждой фазы своя команда.** Ни одна персона не повторяется в другой фазе. Строка «ноль …» и когнитивная дисциплина тоже свои в каждом промпте.
- **У каждого уровня свои люди.** В каждом промпте три роли под уровень: B1, B1–B2, B2. Работает только та, что совпадает с уровнем серии.
- **У каждого языка свой набор промптов**, написанный на этом языке, с командами из своей культуры: британские, американские, французские, итальянские, испанские, русские, немецкие издательства, институты, музеи, словари. Это не переводы английских персон.
- В навыке нет ни образцов текста, ни галереи ошибок, ни имён писателей как ориентиров.

## Языки

| Код | Линия | Папка промптов |
|---|---|---|
| `en-uk` | английский (Великобритания), по умолчанию | `prompts/en-uk/` |
| `en-us` | английский (США) | `prompts/en-us/` |
| `fr` | французский | `prompts/fr/` |
| `it` | итальянский | `prompts/it/` |
| `es` | испанский (Испания) | `prompts/es/` |
| `ru` | русский | `prompts/ru/` |
| `de` | немецкий | `prompts/de/` |

У каждого языка свой справочник `references/per-language/<код>.md`. В нём:

- читатели;
- орфография и типографика;
- регистр по уровням;
- передача имён древних миров;
- запрещённая псевдостарина;
- источники;
- запрещённые формулы;
- подписи элементов книги.

## Что дать на вход

- **Обязательно:** цивилизацию.
- **По желанию:**
  - охват или фокус;
  - число книг (иначе конвейер предложит 8–20);
  - язык (по умолчанию `en-uk`) и уровень (по умолчанию B1–B2);
  - старые материалы как сырьё;
  - реестр линии `line_registry.md`.

## Фазы

| Фаза | Работа | Остановка |
|---|---|---|
| P0 | Приём заказа | ✔ подтвердить заказ |
| P1 | Обзор цивилизации и банк опор | |
| P2 | Концепция серии: книги-окна | ✔ утвердить список книг |
| P3 | Библия серии | |
| P4 | Аудит библии + проверка фактов | |
| P5 | Правка библии | |
| P6 | План историй (slate) | |
| P7 | Аудит плана + проверка выполнимости | ✔ просмотреть план, выбрать режим питчей |
| P8 | Правка плана | |
| P9 | Питч книги | |
| P10 | Аудит питча + проверка фактов | |
| P11 | Правка питча | |
| P12 | Сборка и выдача пакета | ✔ приёмка |

Аудит и правка повторяются, пока не останется 0 Critical и 0 Major. Если одна и та же причина блокирует дважды подряд, конвейер останавливается и предлагает три варианта: принять с оговоркой, переосмыслить, заменить.

## Что получится

- `bible.md`, `slate.md`, `pitches/bookNN_*.md`;
- `name_registry.md`, `sources.md`, `changelog.md`, `delivery_note.md`;
- вся история версий и отчётов.

Библия и один питч — это полный вход для `living-history-book`.
