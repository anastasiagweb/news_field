# living-history-book — как пользоваться

## Что дать на вход
- **Обязательно:** `bible.md` (библия серии) и питч книги `pitches/bookNN_*.md` из `living-history-series`.
- **Желательно:** `slate.md`, `name_registry.md`, `sources.md` серии.
- **По желанию:** готовые книги этой серии — чтобы не повторять концепции, образы и имена.

Конвейер делает только новые книги из питча. Ремонта старых книг нет.

## Фазы
| Фаза | Что происходит | Остановка для вас |
|---|---|---|
| P0 | Спецификация: бюджеты слов, список рассказов, квоты разнообразия, канон серии | ✔ подтвердить |
| P1 | **Досье эпохи до письма**: всё, что нужно десяти рассказам, с источниками и статусом доказанности. Не меньше 12 фактов на рассказ, не меньше 60 пунктов «чего ещё не было», ономастикон, таблица передачи терминов | |
| P2–P4 | Каркас книги: сцены, повороты, развязки, план каждой заметки с привязкой к досье, таблицы разнообразия и антишаблонов → аудит 10 ролей + фактчек → правка | (по желанию) |
| P5 | Черновик: 10 рассказов с заметками, затем вступление с хронологией и послесловие | |
| P6–P7 | Аудит по каждому рассказу (10 ролей) и по книге (4 роли) + полный фактчек всех утверждений → правка только не прошедших рассказов, до 0 Critical / 0 Major | (по желанию) |
| P8 | Издательская правка: орфография, единообразие терминов и имён, шлифовка фраз, повторная проверка утверждений в изменённых фразах | |
| P9 | Финальное чтение и выдача | ✔ приёмка |

Если одна и та же причина блокирует аудит два раза подряд, конвейер останавливается и предлагает три варианта: принять с оговоркой, переосмыслить, заменить рассказ.

## Что получится
- `<book-slug>.md` — готовая книга (B1–B2: около 18–23 тыс. слов);
- `fact_check_final.md` — каждое утверждение с вердиктом и источниками;
- `sources.md`, `delivery_note.md`, `changelog.md`;
- обновлённый реестр имён серии;
- по желанию — бриф для иллюстратора и .docx.

## Что проверяется в каждом рассказе
- **Захватывает:** вопрос-двигатель поставлен в первых 200 словах, есть два поворота, есть решающий выбор героя, концовка — образом, а не моралью.
- **Живой:** конкретика, подтекст, ритм; нет штампов из `anti_formula.md`.
- **Правдив:** факты, мышление, имена.
- **Ясен:** на уровне B1–B2, не больше 6 новых терминов эпохи на рассказ.
- **Самостоятелен:** понятен без других рассказов.
