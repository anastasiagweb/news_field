# Living History — конвейеры

Два навыка (skills) Claude для линии **Living History**. Это сборники из десяти самостоятельных рассказов о простых людях прошлых цивилизаций, у каждого рассказа — честная историческая заметка. Тексты написаны ясным языком уровня B1, B1–B2 (по умолчанию) или B2. Носитель читает их ради удовольствия, учащийся — без мучений.

| Навык | Что делает | Вход | Выход |
|---|---|---|---|
| `living-history-series` | Проектирует серию по одной цивилизации | Цивилизация (+ по желанию старые материалы) | Обзор с источниками, деление на 8–20 книг, библия серии, план из 10 рассказов на книгу, подробный питч каждой книги |
| `living-history-book` | Пишет одну книгу | Библия + питч книги | Готовая книга и файл фактчека с источниками |

## Главный принцип — сильная и своя персона в каждом промпте

Устроено как reading-bridge: у каждого языка свой полный набор промптов, написанный на этом языке.

- **7 языковых линий:**
  - `en-uk` (по умолчанию), `en-us`;
  - `fr`, `it`, `es`;
  - `ru`, `de`.
- **По 23 промпта на язык:** 13 фаз серии и 10 фаз книги.
- **Каждый промпт открывается командой.** Это люди с карьерой, регалиями из реальных институтов своей культуры (издательства, университеты, академии, музеи, библиотеки, словари, экзаменационные системы), убеждениями и тем, чего они не допускают.
- **Персоны нигде не повторяются:**
  - в пределах языка ни одна роль не встречается в двух промптах;
  - строка «ноль…» и когнитивная дисциплина у каждой фазы свои;
  - языки не переводят друг друга: у французской линии французские люди, у русской — русские.
- **Персоны под уровень.** В каждом промпте три роли — для B1, для B1–B2 и для B2. Работает та, что совпадает с уровнем книги. В черновике это три разных читателя, к которым обращается автор.
- **Без «ДНК авторов».** Ни одного имени писателя или учёного как ориентира: только ремесло, убеждения и институты.
- **Ни одного образца текста** и никакой галереи ошибок.

Каждая фаза — свежий взгляд: аудитор не правит, правщик не аудирует. Постоянные правила Managing Editor (максимальное усилие, поштучно, буквально, проверять, а не придумывать, самопроверка дважды) прописаны в обоих SKILL.md.

## Что зашито в доктрину

- **Самостоятельные рассказы.** Лёгкие связи между ними незаметны тому, кто читает один рассказ.
- **Широкая палитра жанров.** Детектив, кража, интрига, путешествие, катастрофа, спор, состязание, комедия, обряд, любовь, потустороннее и другие. Квоты на книгу не дают скатиться в один шаблон.
- **«Контракт правдоподобия» для сюжетных жанров.** Беда типична для эпохи и соразмерна простому человеку. Развязка — только средствами того времени. Совпадение максимум одно и только для завязки. Финал чего-то стоит.
- **Никакого современного мышления** — жёсткое правило.
- **Имена** засвидетельствованы или выведены по правилу. Реестр имён серии исключает повторы. Передача имён — по традиции каждого языка.
- **Фактчек на каждом уровне.** Обзор, библия, план, питчи, досье эпохи до письма, каркас, черновик. Важные утверждения подтверждаются двумя независимыми источниками; в каждом досье есть список того, чего ещё не было.
- **Исторические заметки** 120–180 слов, уровень на ступень выше текста максимум. Отдельно сказано, что известно, что спорно и что придумано.
- **Аннотации и словарики делаются потом**, другими конвейерами.

## Структура

```
shared/references                  — общая доктрина + per-language/<код>.md (правится только здесь)
shared/templates                   — общие шаблоны
skills/living-history-series       — SKILL.md, prompts/<код>/P0–P12 (7 языков), справочники, шаблоны
skills/living-history-book         — SKILL.md, prompts/<код>/P0–P9 (7 языков), справочники, шаблоны
tools/                             — синхронизация общих файлов, проверка структуры и уникальности персон, сборка
dist/*.skill                       — архивы для загрузки в Claude
```

## Установка

- **Claude (веб и приложение):** загрузите `dist/living-history-series.skill` и `dist/living-history-book.skill` в разделе навыков.
- **Claude Code:** скопируйте `skills/living-history-series` и `skills/living-history-book` в `~/.claude/skills/`.

## Изменение доктрины

Правьте `shared/`, затем запустите `bash tools/build_skills.sh`. Проверка `tools/check_links.py` не пропустит:

- повтор персоны, строки «ноль…» или дисциплины внутри языка;
- отсутствие ролей под уровень;
- слова «пример» на любом из семи языков.
