# Living History — конвейеры

Два навыка (skills) Claude для линии **Living History**. Это сборники из десяти самостоятельных рассказов о простых людях прошлых цивилизаций. После каждого рассказа идёт честная историческая заметка. Тексты пишутся на ясном английском уровня B1–B2. Носитель читает их ради удовольствия, а учащийся — без мучений.

| Навык | Что делает | Вход | Выход |
|---|---|---|---|
| `living-history-series` | Разрабатывает серию по одной цивилизации | Название цивилизации (+ по желанию старые материалы) | Обзор цивилизации с источниками, деление на 8–20 книг, библия серии, план из 10 рассказов на каждую книгу, подробный питч каждой книги |
| `living-history-book` | Пишет одну книгу | Библия серии + питч книги | Готовая книга: вступление с хронологией, 10 рассказов с заметками, послесловие; плюс файл фактчека со всеми источниками |

Оба конвейера устроены так же, как соседние детективные (`crime-series-creator` → `crime-reader-pipeline`). Каждая фаза работает по отдельному промпту и пишет файл на диск. Аудиты многоролевые, замечания делятся на Critical, Major, Minor и Nit. Цикл «аудит → правка» повторяется, пока не останется ни одного Critical и ни одного Major.

## Что зафиксировано в доктрине (по итогам разбора «Echoes of Hellas»)

- **Самостоятельные рассказы.** Каждый читается отдельно. Лёгкие связи (общее место, предмет, мелькнувший персонаж) допускаются, но одиночный читатель их не замечает.
- **Разнообразие жанров.** Детектив, кража, интрига, путешествие, катастрофа, суд, состязание, комедия, обряд взросления, любовь, «потустороннее» и другие. Квоты на книгу не дают скатиться в один шаблон.
- **«Контракт правдоподобия» для интриг и детективов.** Беда типична для эпохи и соразмерна простому человеку. Улики и развязка строятся только на средствах того времени: свидетели, клятвы, печати, весы, суд старейшин. Совпадение допускается максимум одно, и только чтобы создать проблему. Никаких принцев с ночными философскими беседами.
- **Никакого современного мышления** — жёсткое правило с каталогом «утечек»: экономика, права, психотерапевтический язык, скепсис, предвидение рассказчика, современные идиомы.
- **Имена.** Только засвидетельствованные или выведенные по правилу. Мифологических и знаменитых имён у простых людей нет. Реестр имён серии исключает повторы.
- **Фактчек на каждом уровне.** Обзор, библия, план книг, питчи, досье эпохи до письма, каркас книги, черновик. Источники ранжируются по уровням A–E. Для важных утверждений нужно два независимых источника, Википедия — только для навигации. В каждом досье есть список «чего ещё не было».
- **Исторические заметки** 120–180 слов, примерно того же уровня, что рассказ (B2 для книги B1–B2). Каждое предложение — проверенное утверждение. Отдельно сказано, что известно, что спорно и что придумано.
- **Только новые книги.** Режима «ремонта» старых книг нет. Старые материалы служат сырьём для серийного конвейера.
- **Аннотации и словарики делаются потом**, другими конвейерами. Здесь получается чистый оригинал.
- **Язык по умолчанию — английский с британской орфографией, уровень B1–B2.** B1 и B2 тоже поддерживаются. Для других языков нужен свой регистровый пакет `cefr_register_<LANG>.md`.

## Структура репозитория

```
shared/                       — общая доктрина линии (правится ТОЛЬКО здесь)
  references/                 — 14 справочников: доктрина, жанры, антишаблоны, ментальность,
                                имена, фактчек, таксономия утверждений, заметки, формат книги,
                                регистр EN, тёмные темы и уважение, аудит, галерея ошибок
  templates/                  — общие шаблоны: отчёт аудита, отчёт фактчека, журнал, состояние, реестр имён
skills/
  living-history-series/      — SKILL.md, 13 промптов (P0–P12), справочники и шаблоны серии
  living-history-book/        — SKILL.md, 10 промптов (P0–P9), справочники и шаблоны книги
tools/
  sync_shared.sh              — копирует shared/ в оба навыка
  check_links.py              — проверяет, что все упомянутые файлы существуют и общие файлы совпадают
  build_skills.sh             — sync + check + сборка dist/*.skill
dist/
  living-history-series.skill — готовые архивы для загрузки в Claude
  living-history-book.skill
```

## Как установить

- **Claude (веб и приложение):** загрузите `dist/living-history-series.skill` и `dist/living-history-book.skill` в разделе навыков (Skills) настроек.
- **Claude Code:** скопируйте папки `skills/living-history-series` и `skills/living-history-book` в `~/.claude/skills/`.

## Как запускать

1. **Серия:** «Запусти living-history-series для Древней Греции. Старые материалы прикладываю». Конвейер остановится для подтверждения:
   - после приёма вводных;
   - после концепции серии (число книг и их список);
   - после плана рассказов (здесь выбирается режим питчей: все книги сразу, пакетом или по мере надобности);
   - на выдаче.
2. **Книга:** «Запусти living-history-book: библия — `bible.md`, питч — `pitches/book01_….md`». Остановки:
   - после спецификации;
   - на выдаче;
   - если цикл правок застрял.

Подробнее — `HOW-TO-USE.md` внутри каждого навыка.

## Как менять доктрину

Правьте файлы в `shared/` и запускайте `bash tools/build_skills.sh`. Скрипт разнесёт изменения по навыкам, проверит ссылки и пересоберёт архивы. Файлы, специфичные для серии или книги, правятся прямо в `skills/<навык>/`.
